適用於「蛤蜊說排程」（Huhclamsay Scheduler）｜最後更新 Last updated：2026-11-24

1. 這個工具是什麼 What this app is

「蛤蜊說排程」是蛤蜊說頻道自己使用的內部工具，用 YouTube API Services 將我們自己製作的影片、縮圖與字幕上傳並排程到我們自己的 YouTube 頻道。

Huhclamsay Scheduler is an internal tool used only by the Huhclamsay channel. It uses the YouTube API Services to upload and schedule our own videos, thumbnails and captions to our own YouTube channel.

2. 使用 YouTube API Services

本工具使用 YouTube API Services。使用本工具即表示同意受 YouTube 服務條款 約束，並適用 Google 隱私權政策。

This app uses YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service, and the Google Privacy Policy applies.

3. 我們存取哪些資料 Data we access

  • 只存取「蛤蜊說」自己頻道的資料：頻道 ID、我們上傳的影片清單與狀態、縮圖、字幕。
  • 不存取、不蒐集任何其他使用者或觀眾的個人資料。

The app only accesses data of our own channel (channel ID, our uploaded videos and their status, thumbnails and captions). It does not access or collect personal data of any other user or viewer.

4. 資料如何使用、儲存與分享 Use, storage and sharing

  • 資料只用來完成上傳、排程影片與設定縮圖、字幕。
  • 授權權杖（OAuth token）只存放在我們自己的一台電腦，檔案權限僅限擁有者讀取，不上傳到任何其他地方。
  • 我們不出售、不分享任何資料給第三方，也不用於廣告。
  • 本工具不使用 cookie 或其他追蹤技術。

Data is used only to upload and schedule our videos and to set thumbnails and captions. OAuth tokens are stored only on our own computer with owner-only file permissions. We do not sell or share any data with third parties, do not use it for advertising, and the app does not use cookies or tracking technologies.

5. 保存期限與刪除 Retention and deletion

授權權杖會保存到我們撤銷授權為止。您可以隨時到 Google 帳戶安全性設定 撤銷本工具的存取權；撤銷後我們會刪除存放的權杖。如需刪除任何相關資料，請來信，我們會在 7 天內處理。

Tokens are kept until access is revoked. You can revoke access at any time via the Google security settings page; we then delete the stored tokens. To request deletion of any related data, email us and we will handle it within 7 days.
